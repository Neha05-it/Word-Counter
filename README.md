# Word Counter

A simple console-based **Word Counter** developed in C++ using Strings and basic programming concepts.

## 📌 About the Project

The Word Counter takes a sentence from the user and analyzes the text.

It calculates the number of words, characters, vowels, consonants, spaces, and identifies the longest and shortest words.

## ✨ Features

- Count total words
- Count alphabetic characters
- Count vowels
- Count consonants
- Count spaces
- Find the longest word
- Find the shortest word
- Accept complete sentences using `getline()`

## 🛠️ Concepts Used

- C++ Strings
- `string`
- `getline()`
- Loops
- `if-else`
- Character Functions
- `isalpha()`
- `tolower()`
- String Length
- String Concatenation
